# Persona Workshop 0.7.2

Windows update status can be read while the updater publishes its next journal
entry. Existing readers keep the previous complete snapshot, and later readers
see the new one. This repairs update and recovery writes that could fail merely
because another process was reading their status.

The change is limited to update records. Executable and runtime replacement,
work admission, account ownership and project data retain their existing rules.
A refused write or uncertain flush remains an error; it is never reported as a
successful update.

Native packages remain available for Windows 11 x64 and ARM64, macOS Intel and
Apple silicon, and Linux x64 and ARM64. They include private Python; no developer
toolchain is required. These previews are unsigned and are not notarized.
