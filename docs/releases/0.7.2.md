# Persona Workshop 0.7.2

Native updates now keep the update worker and the replacement workshop alive
independently of the workshop being replaced. This includes installations
started at sign-in. Existing sign-in settings, account access, projects and
recorded evidence are preserved.

To update an existing 0.7.1 installation, open the installed workshop, then open
the complete 0.7.2 download. The download presents the update and its progress.
Supported recovery restores the previous executable and private runtime without
rewinding project data.

The updater keeps observing the same launch when its acknowledgement is delayed.
It does not repeat an uncertain Start or report an unconfirmed update as
successful. Existing startup definitions keep their original path spelling,
including equivalent macOS path aliases.

This release also repairs Windows update-record writes that could fail while
another process was reading status. Existing readers retain their complete
snapshot; later readers see the new record. Executable replacement retains its
separate protection and ownership checks.

Packages include private Python for Windows 11 x64 and ARM64, macOS Intel and
Apple silicon, and Linux x64 and ARM64. No Python or Rust installation is
required. These previews are unsigned and are not notarized.
