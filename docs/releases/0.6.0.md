# Persona Workshop 0.6.0

The text-only extractor now uses the official ACP Rust SDK 5.0.0 through the immutable Constellation connection integration `e0d6a03fd342b295d349b633d400376efbbe2c40`. The SDK owns framing, request identifiers, reply correlation and callback responders.

Analysis continues to advertise no client tool capabilities, decline permission requests, reject tool-using endpoints, ignore reasoning and unrelated-session output, and bound output and job lifetime. Profile generation and portable exports retain their existing behavior. This is a compiled dependency; installations do not need a shared service.
