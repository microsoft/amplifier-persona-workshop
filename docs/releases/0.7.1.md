# 0.7.1

Windows “start at sign-in” now creates a task for the current installation owner. The previous global logon trigger could fail for an ordinary unelevated account. Existing recognized startup entries remain available without being rewritten; new entries use the owner's logon trigger and a limited interactive principal.

This update adopts the shared native platform correction. It preserves the application's saved account, configuration and data. Platform authorization and model access remain separate from installing the app. Downloads remain unsigned previews.
